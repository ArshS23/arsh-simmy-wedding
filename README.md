# Arsh & Simmy ? Wedding Invitation

Static wedding invitation website. No build tools or installation required.

## GitHub Pages

Upload all files in this folder to the main branch, keeping the assets folder intact. Then open Settings ? Pages, select Deploy from a branch, choose main and / (root), and Save.

Expected address: https://arshs23.github.io/arsh-simmy-wedding/

Edit index.html for the invitation details, styles.css for the design, and script.js for the IST countdown.
